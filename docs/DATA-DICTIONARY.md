# 数据定义

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。

输入字段：cert, device, alias, parent, valid_from, valid_to, minimum, maximum, unit, revoked, measured_at, value, measure_unit, version, uncertainty, unc_unit, coverage_k, spec_min, spec_max。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

校准电压量程闭区间[min,max]，证书日期为半开[valid_from,valid_to)。父证书需在子证书生效日有效；撤销按追溯性撤销处理，所有下游测量拒用。同编号证书定义冲突会使其及下游失去证明力。样例是电压仪器，未处理非线性量程。

## 符合性声明与不确定度（M8）

- `uncertainty`/`unc_unit`：证书的标准不确定度u及其单位（归一化到V）。**允许缺失；缺失在整链合成中传播为“无法判定”，绝不默认为零**。给值不给单位按MISSING隔离，负值按RANGE隔离。
- `coverage_k`：包含因子，空值按机构约定k=2（写入运行清单参数`包含因子k`）；非正数按COVERAGE隔离。
- `spec_min`/`spec_max`：允许偏差（规格限，V，须成对给值，否则SPEC隔离）。留空时声明回退使用该校准证书的量程上下限。
- 整链合成：溯源路径上同一份证书（同一上级标准器，可能在多级证书中重复出现）**只计一次**，去重后按方和根 `u_c=sqrt(sum(u_i^2))` 合成；被多条测量链共享的证书标注“共同系统分量”，既不按跳数重复累加（避免合格件大范围退回），也不当互不相关随机量跨测量平均抵消（避免掩盖共同系统偏差）。每条声明同时保留朴素线性累加基线`naive_linear_uc_v`供对照。
- 扩展不确定度 `U=k·u_c`，声明区间为 `[测量值-U, 测量值+U]`。
- 护基判定：完整区间落入允许偏差判**符合**；整体落在偏差外判**不符合**；区间与规格限相交判**无法判定**（相切按符合）。证书失效、超量程或溯源链断裂时**停止出具**，不生成声明编号；其余测量（含无法判定）均出具带确定性编号的声明。
- 声明编号由`运行幂等键+原始行号`哈希生成：重跑同一批不新增第二份声明；上游记录更新使内容摘要变化形成新批次时，同证书同行号的旧声明置“已重算”并指向新编号，重算链路可追溯。
